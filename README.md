# X Space 录音下载

Chrome 扩展。在已结束并保留回放的 X Space 页面解析录音，保存为 `.m4a`。视频 Space 可以只抽音轨，也可以另存视频。

直播中的场次没有完整录音。主持人没开录制、或回放已删除时，插件会说明原因，不会下一份空文件。

## 安装

1. 打开 `chrome://extensions`。
2. 打开右上角的开发者模式。
3. 选择“加载已解压的扩展程序”，指向这个目录：

```
/Users/glow/dev/projects/x-space-downloader
```

## 使用

打开 `https://x.com/i/spaces/…`，点工具栏图标，或用页面右下角的面板。先解析，确认有回放后再下载。文件在“下载 / X-Spaces”。

公开回放不需要登录。只对你可见的回放，要先在这个 Chrome 里登录 X。

## 限制

- 只下载你本来就能在 X 上播放的回放，不会绕过私密 Space。
- 音频保存为 m4a。视频 Space 的视频是 MPEG-TS（`.ts`），用 IINA 或 VLC 播放。
- 回放地址由 X 签名，过期后需要重新解析。
