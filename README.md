# X Space 录音下载（X Space Downloader）

将已结束且保留回放的 X（Twitter）Space 保存为 `.m4a` 音频文件（视频 Space 可另存为 `.mp4` 或 `.ts` 视频）的 Chrome MV3 扩展。

## 功能

- **音频封装与元数据**：将 Space 回放保存为 `.m4a` 音频，支持自动写入标题、主持人名称、开播日期、Space 链接备注以及主持人头像封面（适用于 AAC / TS 音轨提取回放）。
- **视频 Space 下载**：视频 Space 既可只提取音轨存为 `.m4a`，也可下载完整视频并通过 `mux.js` 无损重封装为系统播放器可直接打开的 `.mp4`，或在设置中改为保留原始 `.ts`（MPEG-TS）。
- **断点续传**：下载分片实时写入扩展私有的源私有文件系统（OPFS）；网络波动或意外中断后再次点击下载，会自动跳过已完成的分片继续下载。
- **过期地址自动刷新**：长录音下载中途若签名的回放分片 URL 过期（HTTP 401/403），后台会自动重新获取播放列表签名并继续拉取剩余分片。
- **页面内悬浮面板**：在 `x.com` / `twitter.com` 的 Space 页面右下角显示下载面板，自动跟随 X 网页的浅色/深色背景主题，支持本场关闭或永久隐藏。
- **独立弹窗与设置页**：支持在工具栏弹窗中粘贴任意 Space 链接或 ID 解析下载，并提供保存子目录、文件名模板、视频格式、并发数等设置项。

## 安装

环境要求：Chrome 116 及以上版本。本扩展无需构建步骤，可直接加载源码目录：

1. 在 Chrome 地址栏打开 `chrome://extensions`。
2. 开启右上角的“开发者模式”。
3. 点击左上角“加载已解压的扩展程序”，选择本仓库目录。

## 使用

1. **在 Space 页面下载**：打开 `https://x.com/i/spaces/...`，使用页面右下角的悬浮面板，或点击浏览器工具栏中的扩展图标（弹窗会自动填入当前页链接并解析）。
2. **粘贴链接下载**：在任意页面点击工具栏扩展图标，粘贴 Space 链接（或 Space ID）后点击“解析”。
3. **保存文件**：解析显示“已结束 · 有回放”后，点击“下载录音”（若该场包含视频画面，还会出现“下载视频”按钮）。下载完成后文件默认保存在系统下载目录下的 `X-Spaces` 子目录中。

公开 Space 回放无需登录即可解析下载（扩展会自动申请 X 访客令牌）；仅登录可见或受限的回放，请先在当前 Chrome 中登录拥有访问权限的 `x.com` 账号。

## 设置项说明

在弹窗底部点击“设置”，或在 `chrome://extensions` 的扩展详情中打开扩展选项即可修改以下配置（实时保存在 `chrome.storage.sync`）：

| 设置项                             | 默认值                    | 说明                                                                                                                |
| ---------------------------------- | ------------------------- | ------------------------------------------------------------------------------------------------------------------- |
| 保存子目录（`folder`）             | `X-Spaces`                | 相对于浏览器默认下载文件夹的子路径；留空则直接保存在下载根目录。非法路径字符与 `..` 会自动清理。                    |
| 文件名模板（`template`）           | `{date} {handle} {title}` | 输出文件名模板（不含扩展名，最长截断为 120 个字符）。支持下方列出的占位符。                                         |
| 视频保存格式（`videoFormat`）      | `mp4`                     | `mp4`：通过 `mux.js` 将 MPEG-TS 无损重封装为 MP4（重封装失败时自动回退为 `.ts`）；`ts`：直接拼接原始 MPEG-TS 分段。 |
| 最大并发连接数（`maxConcurrency`） | `0`                       | 范围 `0`–`32`。设为 `0` 时按设备 CPU 核数、内存和网络类型自动选择并发上限，并根据分片响应耗时动态升降。             |
| 写入音频元数据（`embedMetadata`）  | 开启                      | 在封装 `.m4a` 时写入标题、艺术家（主持人）、专辑（`X Spaces`）、ISO 开播时间、Space 链接备注及 JPEG/PNG 封面图。    |
| 显示页面面板（`showPanel`）        | 开启                      | 在 Space 页面右下角挂载悬浮下载面板。点击面板上的“不再显示”会关闭此项。                                             |

文件名模板可用占位符：

- `{date}`：开播日期（本地时间 `YYYY-MM-DD`，无开播时间时取当前日期）
- `{time}`：开播时间（本地 24 小时制 `HHMM`）
- `{handle}`：主持人账号（格式如 `@username`，缺失时回退为主持人显示名）
- `{name}`：主持人显示名
- `{title}`：Space 标题
- `{id}`：Space ID

## 限制

- **仅限可播放回放**：只能下载你在当前 Chrome 中本来就能正常收听或观看的 Space 回放，无法绕过账号权限或付费/私密限制。
- **不支持直播录制**：正在直播（`Running`）或尚未开始（`NotStarted`）的 Space 无法下载；需等待直播结束且主持人保留回放、平台生成完整播放列表（含 `#EXT-X-ENDLIST`）后方可下载。
- **单任务串行下载**：同一时间只允许进行一场 Space 下载任务；下载期间其他 Space 面板会提示等待当前任务完成或取消。
- **文件体积上限**：音频 `.m4a` 封装使用标准 32 位 MP4 偏移与 `mdat` 盒大小，单文件原始音频数据不支持超过 4 GB；单个播放列表最多支持 20,000 个分片。

## 常见问题排查

- **提示“Space 接口编号已失效”或“X 的 Space 接口变了”**：X 会不定期轮换 GraphQL `AudioSpaceById` 的 `queryId`。扩展遇到失效编号时会自动扫描当前 Space 页面脚本或拉取 `x.com` 首页脚本提取新编号并缓存。若在非 Space 页面通过弹窗解析失败，请先在浏览器中打开任意一场 Space 页面，再点一次解析。
- **请求失败（429）或速度变慢**：触发了 X 接口或 CDN 的频率限制。分片下载遇到 `429` 或 `5xx` 时会自动退避重试并缩减并发连接数；若解析阶段返回 `429`，请等待几分钟后再试。
- **提示“这个回放在当前地区不可用”**：X 返回了带 `/geoblocked/` 标记的播放地址，说明该场回放在当前网络出口所在地区受限。
- **提示“回放还在生成”或“回放还没有生成完整文件”**：直播刚结束时，平台转码与回放列表封尾需要数分钟，请稍后重新点击“解析”。
- **找不到 Space 或无权访问私密/受限场次**：确认链接无误，并确保已在当前 Chrome 窗口登录了有权限收听该场 Space 的 `x.com` 账号。
- **下载中途断网或浏览器重启导致中断**：无需清理缓存，重新打开该 Space 并点击下载，扩展会校验 OPFS 中已保存的分片并从断点继续。
- **Space 页面右下角的悬浮面板不见了**：若只在本场点过“关闭”，刷新页面即可恢复；若点过“不再显示”，请点击工具栏扩展图标 -> 底部“设置” -> 重新勾选“在 Space 页面右下角显示下载面板”。
