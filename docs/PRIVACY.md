# 隐私权政策（Privacy Policy）

更新日期：2026-11-17

“X Space 录音下载”（X Space Downloader）是一款在浏览器本地运行的 Chrome 扩展。我们重视用户隐私：**本扩展不包含任何统计分析（Analytics）、遥测或广告代码，未架设任何开发者后端服务器，不会向开发者或任何第三方收集、上传、出售或共享您的任何个人数据。**

## 扩展访问的数据及用途

1. **X（Twitter）登录状态 Cookie（`auth_token` 与 `ct0`）**
   - **访问方式**：仅在您主动解析或下载 Space 回放时，由浏览器本地后台通过 `chrome.cookies` 读取 `https://x.com/` 或 `https://twitter.com/` 下的 `auth_token`（仅判断是否存在）与 `ct0`（用于构造 X 接口要求的 `x-csrf-token` 请求头）。
   - **用途**：以您当前已登录的浏览器会话直接向 X 官方接口请求您有权收听的 Space 回放信息。对于无需登录的公开回放，若浏览器未登录 X，扩展会直接向 X 官方接口申请临时访客令牌（Guest Token）。
   - **去向**：Cookie 与令牌仅保存在当前浏览器内存中，且只随直接发往 X 官方域名的 HTTPS 请求使用，绝不会发送给开发者或任何其他服务器。

2. **Space 页面链接与客户端脚本地址**
   - **访问方式**：当您访问 `x.com` / `twitter.com` 的 Space 页面或在扩展弹窗中输入链接时，扩展会在本地读取该页面 URL 以提取 Space ID；当 X 轮换前端接口编号（GraphQL `queryId`）时，扩展会读取 Space 页面引用的 X 官方前端脚本 URL（位于 `abs.twimg.com`）以提取最新接口编号。
   - **用途**：识别目标 Space 并在 X 更新前端代码后保持解析功能可用。扩展不会读取您的时间线内容、私信、账号密码或其他浏览历史记录。

## 本地存储说明

所有运行数据均保存在您本地的 Chrome 浏览器中：

- **`chrome.storage.sync`**：保存您的扩展偏好设置（下载子目录名称、文件名模板、视频封装格式、最大并发连接数、音频元数据开关、页面面板显示开关）。若您开启了 Chrome 账号同步，该配置由浏览器自身同步。
- **`chrome.storage.local`**：缓存从 X 前端脚本中识别出的公开接口编号（`queryId`）。
- **`chrome.storage.session`**：仅在内存会话中暂存当前下载进度卡片、有效期 90 分钟的 X 临时访客令牌及有效期 10 分钟的回放播放列表地址；关闭浏览器后自动清除。
- **扩展源私有文件系统（OPFS）**：下载过程中将音视频分片暂存在扩展沙盒私有的 OPFS 目录中，以支持断点续传并降低内存占用。当文件成功保存到您的系统“下载”文件夹后，对应临时目录会立即自动删除；若下载中途取消或中断未继续，残留的临时分片会在后续启动下载且距上次更新超过 7 天时自动清理。卸载扩展时，浏览器会一并清除上述全部存储空间。

## 网络通信范围

本扩展仅通过 HTTPS 与 X / Twitter 官方及其音视频分发网络直接通信，包括：

- `x.com`、`*.x.com`、`twitter.com`、`*.twitter.com`（获取 Space 元数据、回放流状态与访客令牌）
- `*.twimg.com`、`*.pscp.tv`（读取公开前端脚本编号、主持人头像封面图以及 HLS 回放播放列表与音视频分片）

除上述官方域名外，本扩展不会向任何外部服务器发起网络连接。
